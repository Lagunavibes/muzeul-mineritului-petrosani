# Muzeul Mineritului din Petroșani

Site omagial bilingv (RO / EN) pentru Muzeul Mineritului din Petroșani, Valea Jiului.

**Live:** https://lagunavibes.github.io/muzeul-mineritului-petrosani/

Site neoficial. Muzeul este administrat de Primăria Municipiului Petroșani.

## Local

Deschideți `index.html` sau:

```bash
python3 -m http.server 8080
```
